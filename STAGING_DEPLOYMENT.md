# Staging Deployment Retired

Staging is not an active deployment or release-acceptance target for this project. This page is a retirement notice, not a deployment procedure. Do not reuse historical host, DNS, TLS, port, or volume settings for a new operation.

The checked-in staging Compose and application compatibility code remain legacy references. CI does not deploy staging; its focused backend configuration tests still cover some legacy settings. Production deployments and acceptance use the [operations runbook](docs/OPERATIONS_AND_DEPLOYMENT.md).
